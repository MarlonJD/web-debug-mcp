# Reliability

The first increment favors bounded, recoverable local sessions over background persistence. A failed initial browser connection removes its session record and releases owned resources; a failed repeated launch candidate is closed atomically while the prior usable adapter remains selected.

## Reliability contract

| Risk or invariant | Detection | Recovery | Verification |
| --- | --- | --- | --- |
| Browser executable or CDP endpoint is missing | `BROWSER_EXECUTABLE_REQUIRED` or adapter connection error | Provide an explicit executable path or CDP endpoint; no arbitrary browser is launched | `npm run typecheck`; live browser smoke when Chromium is available |
| Invalid project root | `PROJECT_ROOT_INVALID` | Pass a real directory containing the target project | `capabilities.test.ts` |
| More than eight active sessions | `SESSION_LIMIT_REACHED` | Close an existing session, then retry | Session manager contract |
| Browser wait or action hangs | Playwright/WebDriver action timeout capped at 30 seconds and shared operation deadline | Inspect the bounded error, capture state, and close the session; no elapsed-only waits are accepted | Adapter implementation and fixture flow |
| Browser process exits | Playwright/CDP operation error | Close the session, retain artifact paths, start a fresh isolated session | Live smoke when a browser is available |
| Initial redirect, action, reload, or secondary page leaves the selected origin | `NAVIGATION_ORIGIN_BLOCKED`; Chromium aborts selected-target top-level requests plus frame-less popup documents, and Safari post-navigation quarantine closes escaped WebDriver state | Close the failed session and fix the local route; do not broaden origin authority for ordinary debugging | Chromium/Safari origin-policy tests and live smoke |
| Node WebSocket runtime is unavailable | Safari BiDi client detects missing global WebSocket support and returns a bounded warning instead of throwing an unhandled runtime error | Use Node 20.10+ with `--experimental-websocket` or Node 21+ for BiDi console evidence; retain WebDriver and disclosed network fallback evidence otherwise | Safari adapter test and `npm run smoke:safari` |
| Evidence grows without bound | Ring buffers, item caps, text caps, and eight-frame debugger limit | Use the returned truncation warning and request a narrower follow-up | Redaction and evidence tests |
| Framework, WebDriver, evaluation, or MCP output exceeds its byte budget | Streaming reader, bounded sanitizer, evaluation cap, output schema, and final result-size check | Narrow the requested evidence; overflow returns a stable error and never partial success | HTTP/redaction/MCP response tests |
| Screenshot files accumulate or exceed their disk budget | Every manual and matrix capture applies a 4 MiB file cap plus a four-file/16 MiB per-session quota; timed-out, oversized, and oldest files are deleted | Read retained handles promptly; quota pruning returns stable `ARTIFACT_NOT_FOUND`, and exact-session delete remains available | Session quota, matrix capture, late-write, and resource-pruning tests |
| MCP process receives SIGINT/SIGTERM, stdin EOF/close, transport close, or idle TTL | Shared idempotent registry shutdown path with manager-derived absolute session reconciliation | Mark `terminating`, reject new requests, close owned sessions/transport once, preserve terminating state during request finalization, remove the exact registry record, and let the event loop drain | Process lifecycle, repeated/concurrent close accounting tests, and stdio smoke |
| Next runtime endpoint is unavailable or returns malformed SSE | `NextAdapter` timeout/JSON-RPC warning | Keep browser evidence, report the Next capability warning, and retry after the dev server is ready | `next-adapter.test.ts` and `npm run smoke:next` |
| Next development log is missing, outside the project, or too large | `NextAdapter` path boundary, byte/line caps, and warning | Keep the Next metadata and browser evidence; inspect the returned warning or the local dev server directly | `next-adapter.test.ts` and `npm run smoke:next` |
| Next route compile or Server Action lookup is unavailable | `web_next_inspect` returns a bounded error/warning from the local Next MCP endpoint | Keep the session and capture evidence; retry after the route/server manifest is ready | `next-adapter.test.ts` and `npm run smoke:next` |
| Vite debug endpoint is unavailable or returns malformed JSON | `ViteAdapter` timeout/HTTP/JSON warning | Keep browser evidence, report the Vite capability warning, and verify the Vite plugin is installed | `vite-adapter.test.ts` and `npm run smoke:react-vite` |
| Vite transform history is missing or too large | Plugin keeps 200 source snapshots, 32 KiB/module, and 12 KiB/diff bounds; absence remains nullable | Keep module graph/HMR evidence and report a missing diff rather than failing the session | `vite-adapter.test.ts` and `npm run smoke:react-vite` |
| React commit profiling data is unavailable or grows too large | Bridge uses bounded commit history, a capped flat flamegraph, Fiber weak maps, and nullable duration fields | Keep component/state evidence and report the React bridge warning; do not fail the browser session | `react-fixture-contract.test.ts` and `npm run smoke:react-vite` |
| Angular debug globals are unavailable or state grows too large | DOM-host discovery and descriptor serialization are capped; optimized builds return an explicit warning | Keep generic browser evidence; do not inspect private Ivy state or fail the session | `angular-adapter.test.ts` and `npm run smoke:angular` |
| Vue hook chaining is unavailable or component events grow too large | Exact hook listeners, app/component caps, and no DOM-private fallback | Return bounded warning/empty runtime detail while preserving generic browser and Vite evidence | `vue-adapter.test.ts` and `npm run smoke:vue-vite` |
| Safari remote automation is disabled or WebDriver/BiDi is unavailable | `SafariAdapter` returns a bounded startup or BiDi warning; the smoke reports `status: "blocked"` when a required BiDi console guardrail is unavailable and discloses the Performance Resource Timing fallback when network events are absent | Enable Safari remote automation or provide a loopback WebDriver endpoint; use Chromium when CDP debugger evidence is required | `safari-adapter.test.ts` and `npm run smoke:safari` |
| Replay frames grow without bound, contain input values, lose their starting state, or cannot be safely restored | Session keeps eight frames, resets verification frames per attempt with monotonic indices/attempt ids, keeps scenario frames capture-only, sanitises fill/select actions, and restores non-navigation-first flows only from the private retained session start | Rerun the flow when the start frame was truncated, input was sanitised, or restore is refused | Session manager replay contract and React/Vite smoke |
| Remote CDP target is not approved or unreachable | Endpoint host/protocol policy fails closed before connection; explicit attached sessions report non-isolation | Enable `allowRemote` only for a known endpoint and retry with a bounded connection timeout | `chromium-policy.test.ts` and local attach smoke |
| Reproduction or fix verification is flaky | Adaptive quick/standard/strict state machines classify decisive, retryable, permanent, unavailable, cancelled, and exhausted attempts | Retry only within the total phase deadline; conflicting post-fix observations remain `inconclusive`/flaky | Session manager contract and repair demos |
| Session mutations race or close during verification | One exclusive abortable lease per session; competing mutations return `SESSION_BUSY` | Propagate cancellation, wait at most five seconds for cleanup, then close owned resources and purge private scenarios/evidence | Session manager cancellation/concurrency tests |
| Next inspection races browser/session mutation | `web_next_inspect` uses the same lease and operation context as browser actions | Wait for the active operation or cancel it; an interrupted adapter makes the session unusable before lease release | Next inspection lease/cancellation test |
| Adapter work outlives cancellation or deadline | Lease tracks every adapter promise and treats interrupted work as unusable until the owned adapter is boundedly closed | Never release the lease for another mutation while late work can affect a target; attached targets are detached, not closed | Session manager late-completion/close tests |
| Redaction collides with a temporary screenshot handle | The session-owned path is scrubbed before serialization | Return a null screenshot handle and bounded warning; do not multiply or relocate the artifact | Session manager redaction/capture tests |
| Browser restart is mistaken for application reset | Attempt reset metadata distinguishes fresh browser state from server/database state | Require an explicit observable server-state reset contract; otherwise return `inconclusive` | Adaptive scenario policy tests |
| Required browser evidence is stale or unavailable | URL, DOM, and console observations report state, freshness, and provenance | Do not satisfy checks from paused/stale DOM or unavailable Safari BiDi console; keep optional framework warnings | Adapter and adaptive verification tests |
| Full evidence disagrees with checks-only state | Representative capture re-evaluates the complete failure/acceptance contract under the same attempt id | Mark the attempt conflicted and return `inconclusive`; never promote a conflicted pass to `verified` | Session manager authoritative-capture tests |
| Optional framework enrichment is slow or unavailable | Selected React/Angular/Vue snapshots run concurrently under one local budget; screenshot and Next/Vite use bounded child work | Preserve authoritative browser URL/DOM/console evidence, track pending cleanup, and report warnings; caller cancellation still cancels the root operation | Chromium/session manager optional-enrichment tests |
| Verification output grows with retries | At most five summaries per phase, eight replay frames, bounded observed text, and a 256 KiB deterministic result budget | Keep one representative full evidence bundle per phase and prune optional enrichment before decisive fields | Result-bound tests and harness check |
| Elevated TLS/auth request escapes the target | Exact approved-origin request/WebSocket/page guards and `serviceWorkers: "block"` are installed before first page; storage state is private and project-contained | Fail closed with `APPROVED_ORIGIN_BLOCKED`/auth policy errors; never broaden the origin or install a CA | Local-fidelity smoke and auth/escape tests |
| Computed semantics differ from a DOM summary | Locator checks/waits use a fresh adapter `probe` for count, visibility, enabled, checked, and text | Return unavailable/inconclusive when live probe cannot run; optional AX data cannot make a check pass | Locator probe tests and matrix flow |
| Matrix candidate fails or is cancelled | Each of at most 20 sequential viewport units owns a fresh adapter and shared deadline | Close only that candidate in `finally`; preserve canonical adapter/target/replay and downgrade to unavailable/inconclusive | Matrix orchestration tests |
| Registry is malformed, stale, busy, or identity-drifted | Owner/mode/symlink/cap checks, per-instance lock, heartbeat (`15s`), stale diagnostic (`45s`), and Linux/Darwin identity revalidation | Report and skip; signal neither a changed process nor an unregistered legacy process | Cleanup CLI/process tests |
| Closed sessions or private auth inputs accumulate in memory | Active-only session map, explicit secret/start-option destruction, and 32-entry sanitized tombstone cap | Query the bounded closed status or start a new session; evicted tombstones return `SESSION_NOT_FOUND` | Session manager tombstone/secret-purge test |
| Fixture server starts silently, exits early, or leaves a framework grandchild | Shared readiness deadline, early-exit race, awaited SIGTERM, and POSIX command-owned process-group SIGKILL escalation | Inspect the bounded readiness error; rerun only after the exact fixture group is gone | Direct-child/stubborn-grandchild helper tests and live smokes |

## Enforced 0.3.x bounds

Scenario actions `100`; locator values/select values `500`; fill values `10,000`; accessible names `300`; press keys `10`; probe properties `5`; checkpoints `16`/`32` total probes/`8` per checkpoint; decisive observations `64`; viewports `4`; attempts `5`; matrix units `20`; AX nodes `128`; suggestions `32`; auth file `65,536` bytes/`32` cookies/`8` origins/`128` storage items; action waits `30,000 ms`; phase budgets `15/60/120s`; MCP requests `150s`; framework/WebDriver responses `262,144` bytes; Safari screenshot transport `8 MiB`; retained screenshots `4 MiB` each and `4` files/`16 MiB` per session; screenshot resources `64` handles with at most `1h` TTL; evidence bundles `98,304` bytes; complete MCP results `262,144` bytes; text previews `8 KiB`; replay frames `8`; closed tombstones `32`; registry entries/records `128/64`; records `16,384` bytes; cleanup report `65,536` bytes and `64` detail rows. Positive idle TTL overrides are `10,000..3,600,000 ms`; `0` disables automatic expiry.

## Operational signals

MCP responses carry structured error codes for expected failures. Evidence carries warnings for truncation, unavailable DOM/screenshot data, non-isolated external attachment, and unavailable optional Next runtime tools. Diagnostic text must go to stderr so the MCP stdout stream remains parseable.

## Recovery boundary

Non-empty temporary artifacts are retained after default close so the agent can inspect the evidence, but only within the session file/count/byte quota; empty session directories are removed automatically. `artifactPolicy: "delete"` removes only the exact owned session directory and is idempotent through the sanitized tombstone. Opaque resource handles have a one-hour upper-bound TTL: earlier quota pruning can invalidate an older handle with stable `ARTIFACT_NOT_FOUND`. The project has no database, hosted daemon, migration, deployment, or rollback surface in this increment.
