# Reliability

The first increment favors bounded, recoverable local sessions over background persistence. A failed initial browser connection removes its session record and releases owned resources; a failed repeated launch candidate is closed atomically while the prior usable adapter remains selected.

## Enforced 0.12.0 bounds

Scenario actions `100`; locator values/select values `500`; fill values `10,000`; accessible names `300`; press keys `10`; probe properties `5`; checkpoints `16`/`32` total probes/`8` per checkpoint; decisive observations `64`; viewports `4`; attempts `5`; matrix units `20`; AX nodes `128`; suggestions `32`; auth file `65,536` bytes/`32` cookies/`8` origins/`128` storage items; action waits `30,000 ms`; phase budgets `15/60/120s`; MCP requests `150s`; framework HTTP/native Safari MCP responses `262,144` bytes; WebMCP arguments `64` keys/object, depth `8`, `128` nodes, `100` key characters, `2,000` UTF-8 bytes/leaf, `16,384` serialized bytes; WebMCP results `8,192` UTF-8 bytes; WebMCP metadata `16` tools/`32,768` serialized bytes; retained screenshots `4 MiB` each and `4` files/`16 MiB` per session; screenshot resources `64` handles with at most `1h` TTL; evidence bundles `98,304` bytes; complete MCP results `262,144` bytes; text previews `8 KiB`; replay frames `8`; closed tombstones `32`; post-reconciliation registry entries/records `128/64`; startup reconciliation scans at most `192` owned record/sidecar entries and `64` records; records `16,384` bytes; cleanup report `65,536` bytes and `64` detail rows. Positive idle TTL overrides are `10,000..3,600,000 ms`; `0` disables automatic expiry.

## Operational signals

MCP responses carry structured error codes for expected failures. Evidence carries warnings for truncation, unavailable DOM/screenshot data, non-isolated external attachment, and unavailable optional Next runtime tools. Diagnostic text must go to stderr so the MCP stdout stream remains parseable.

## Recovery boundary

Non-empty temporary artifacts are retained after default close so the agent can inspect the evidence, but only within the session file/count/byte quota; empty session directories are removed automatically. `artifactPolicy: "delete"` removes only the exact owned session directory and is idempotent through the sanitized tombstone. Opaque resource handles have a one-hour upper-bound TTL: earlier quota pruning can invalidate an older handle with stable `ARTIFACT_NOT_FOUND`. The project has no database, hosted daemon, migration, deployment, or rollback surface in this increment.

## Diagnostic observation cleanup

Chromium diagnostic windows have a 15-second operation deadline and a bounded 0-5000 ms settling interval. Each cleanup command has a separate one-second bound even after request cancellation. Unconfirmed stop/disable returns `DIAGNOSTIC_CLEANUP_FAILED` and marks the session unusable. Close retries cleanup before detach. Source enrichment has separate small budgets and explicitly reports unavailable maps rather than inventing locations. Document replacement invalidates the window's source associations and coverage. Verification never enables precise coverage.

## Safari 27 session recovery

On Safari 27.0 (22625.1.29.11.27), a normal already-running Safari process may advertise automation availability yet reject a classic WebDriver session with the native log message `Safari was not launched for automation`. A live control on 2026-10-13 reached `AppIsReady` and stalled after requesting a new session. Explicit macOS capabilities and longer diagnostic waits did not resolve it.

The verified recovery is to obtain the user's approval, use Safari's **Quit and Keep Windows**, release only the conflicting client-owned automation instance, and let classic safaridriver launch its own `--automation` process. A fresh session then returned HTTP 200 in approximately 2032 ms. Native Safari MCP and classic WebDriver must not concurrently own that same automation instance: the conflicting case returns `already paired with another WebDriver session`. Do not kill unrelated drivers, reset profile data, disable security controls, or silently close personal Safari. After testing, close the owned automation process and reopen normal Safari; all five saved tabs were verified restored in this run.

The current adapter uses the official native MCP driver instead of the experimental BiDi route. `SAFARI_MCP_TIMEOUT` reports bounded startup/command failures, `SAFARI_SESSION_IN_USE` identifies a conflicting owner, and caller cancellation remains `REQUEST_CANCELLED`. Timed-out or cancelled native clients close before another attempt can proceed. None of these errors terminates personal Safari. Doctor checks executable availability only; it does not launch Safari or claim console delivery.

The experimental BiDi endpoint acknowledged subscriptions without forwarding them to WebKit or delivering logs. The native MCP control returned actual Inspector records, including `Payment validation failed` at `app.js:8`. This is a transport replacement, not a claim that Apple's BiDi implementation was fixed. The old endpoint settings and BiDi client were removed. Inspector buffers are tab-scoped, bounded, redacted, and drained on reset. A successful empty read remains unavailable until actual console delivery has been observed; a later failed read makes the observation unavailable again.

The local smoke now exercises real errors, reset, navigation, native form input, source coordinates, and the screenshot privacy boundary. Native network collection remains best effort; missing Inspector requests use explicitly labeled Performance Resource Timing. Release/public plugin validation is pending.

A final native MCP control on 2026-10-13 started successfully while normal Safari remained open and captured a real error record with `safari-mcp` provenance. The five restored personal tabs were unchanged. The older classic-driver quit/restart workaround was not needed for this native control.

Malformed, foreign-tab, disconnected, or truncated native console observations cannot satisfy `noConsoleErrors`; a reset drains native buffers before clearing the retained local evidence.
