# Web Debug 0.13.0

Web Debug now returns compact reproduction and verification results while retaining the complete authoritative observations behind bounded immutable resources. The release also adds stronger observable checks, safer call guidance and project logs, and explicit framework recovery without adding public tools.

- Scenario and verification summary schema 7 retains every attempt/check outcome, isolation, repetition, completion and unavailable fact. Full collection still determines the verdict. Read referenced evidence through MCP resources or `web_issue_capture` with the recorded profile; reads do not replay browser actions. Verification screenshots are resource-only.
- Record full-rectangle viewport checks, center-point obstruction, finite decimal DOM numbers with tolerance, exact same-origin response status and real network completion. Optional completion conditions use observable state and bounded deadlines; minimum post-fix attempts preserve the requested repeated verification.
- Canonical tool schemas include validated examples. Rejected arguments return safe field paths, choices and constraints without echoing private rejected values.
- Explicit project-relative `.log` capture uses contained no-follow reads and bounded output. Raw and recognized encoded session/auth input is masked before truncation. Short private inputs preserve semantic locator kinds and host metadata; masked names/file identifiers retain their wire bounds.
- Framework detection retains conflict provenance, offers grounded host selection and exact workspace-root recovery, and preserves real Next action/source/log correlation.
- Repository benchmark infrastructure pins small upstream examples, hidden defects, reusable ordinary browser evidence and independent oracle checks. The separate 54-run Astra Max/6.1 Sol Max experiment found no general speed/token saving or requirement to use the plugin. It measured a preserved candidate before the final focused privacy fixes and is not a benchmark of the final release.

## Migration

Clients reading former full reproduction/verification payloads must consume summary schema 7 and follow evidence references for detailed observations. Authoritative evidence remains schema 4; manual capture remains schema 6 and the recorded wrapper is schema 1. References belong to one live session and can expire after private-input changes, close, quota eviction or one hour. Missing references fail explicitly.

The MCP catalog remains 13 tools. Inputs are strict; remove unsupported extra fields and use the advertised examples. The bundled plugin and standalone runtime pin are `web-debug-mcp@0.13.0`. Safari still requires Safari 27+ and exposes its existing visible/non-isolated and telemetry limits. No hosted, production or remote-browser authority is added.
