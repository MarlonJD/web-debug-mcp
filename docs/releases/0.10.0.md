# Web Debug MCP 0.10.0

`0.10.0` makes evidence collection more selective and explicit, tightens the bundled workflow guidance, and adds Google Antigravity plugin compatibility. The public MCP catalog remains exactly 13 tools.

## Highlights

- Adds manual-capture schema 6 profiles for summary, full, explicit-surface, and session-bound delta collection, with per-surface freshness states.
- Keeps optional enrichment opt-in, suppresses screenshots where privacy or direct WebMCP rules require it, and preserves bounded redacted evidence.
- Narrows browser debugging and manual-parity workflow routing so live Web Debug work remains Gate-0-bound and qualification execution stays repository-native.
- Adds a root Antigravity manifest and MCP configuration that use the same pinned local stdio runtime and bundled skill layout as the Codex/Claude distribution.
- Expands deterministic evaluation contracts and records scoped browser, authority, and command-containment evidence without claiming general model-quality results.

## Compatibility and verification

The release retains loopback-first browser policy, fail-closed task binding, and Safari WebDriver/BiDi as the internal Safari transport. The release gate covers deterministic tests, type checking, build, verification, skill/plugin validation, exact Node 20/22/24 archive handshakes, npm/GitHub publication, and Codex plugin installation. The exact evidence is recorded in the active `release-0-10-0` ExecPlan; current-task tool binding still requires a real bundled `web_project_detect` Gate 0 call after a Codex restart or new task where needed.
