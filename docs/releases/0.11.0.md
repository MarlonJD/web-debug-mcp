# Web Debug MCP 0.11.0

`0.11.0` adds bounded agent-readable interactive UI capture for local browser debugging while preserving the existing 13-tool MCP facade. The release also documents the exploration-to-native-test handoff inspired by Marionette MCP workflows.

## Highlights

- Adds the selected `interactiveElements` capture surface to `web_issue_capture`, with visible/actionable candidates, existing locators, live match counts, enabled/checked state, and viewport geometry.
- Chromium validates semantic, test-id, label, and text locators against the live page; Safari reports only stable CSS locators from `id`/`data-testid` and discloses its capability boundary.
- Bounds all interactive names/text/geometry and excludes hidden/non-actionable elements and input values from the agent-readable map.
- Keeps the map out of summary captures unless explicitly selected, while full/include/delta projections can request it.
- Updates the bundled workflow skills so agents can explore with the map and promote confirmed flows into deterministic repository-native tests; WebMCP remains limited to approved product capabilities.

## Compatibility and verification

The release retains loopback-first browser policy, fail-closed task binding, bounded redaction, and Safari WebDriver/BiDi as the internal Safari transport. The release gate covers deterministic tests, type checking, build, verification, skill/plugin validation, exact archive/stdio handshakes, npm publication, and Codex plugin installation. Figma design parity is not included and remains deferred under DEBT-008 until an approved source and comparison thresholds exist.
